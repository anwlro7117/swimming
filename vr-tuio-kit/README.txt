VR실 TUIO 키트
==============

구조
  YTS.exe ──(TUIO / UDP 3333)──> bridge.js ──(웹)──> 크롬 벽 화면 3개 + 조작 모니터 관제 화면

준비 (VR실 PC 1회)
  1. Node.js LTS 설치 (nodejs.org). 인터넷 없으면 설치 파일 USB로 옮긴다.
  2. 이 폴더를 통째로 복사한다. 예: C:\vr-tuio-kit
  3. 씽킹플레이 콘텐츠는 끈다. 같은 3333 포트를 쓴다.

순서
  1. YTS.exe 실행. TUIO 켜짐 확인 ("TUIO UDP (T)" 버튼).
  2. 1_bridge_start.bat  → 검은 창 그대로 둔다. 닫으면 끊긴다.
  3. 0_monitor_number.bat → 모니터마다 큰 번호가 뜬다. 번호를 적는다.
  4. config.json 화면마다 "screen": {"x": 왼쪽 픽셀, "y": 위 픽셀} 이 있으면 그 위치 화면에 띄운다.
     (vr360 "화면 감지" 표의 left/top 값). "screen" 지우면 "monitor" 번호(윈도우 DISPLAY 번호)로 찾는다.
     조작 모니터 = "operatorScreen" 또는 "operatorMonitor".
     (조작 화면 표에서 고치고 "저장"을 눌러도 된다)
  5. 2_screens_open.bat  → 벽 화면 3개에 테스트 화면, 조작 모니터에 관제 화면.
  6. 관제 화면 "모서리 보정": 화면 골라 시작 → 그 화면 노란 원 좌상단 → 우하단 순서로 손바닥 대고 떼기.
     벽 화면 3개 다 하고 "저장". 화면들은 F5(또는 3번 닫고 2번 다시).
  7. 3_screens_close.bat → 화면 전부 닫기.
  (선택) 2b_sensor_map.bat → 벽마다 8×4 칸. 칸마다 손바닥으로 3번씩 톡톡 → 잘 잡히는 곳 초록, 안 잡히는 곳 빨강.
        어느 벽·어느 자리가 게임하기 좋은지 확인용. R 키 = 지우기.

확인 포인트
  - 관제 화면 "TUIO 수신 중" 초록 → 센서 신호 들어옴.
    빨강이면: YTS TUIO 꺼짐 / 포트가 3333 아님 / 씽킹플레이가 포트 점유.
  - 보정 후 손 대는 곳에 원이 따라오면 성공.
  - 바닥 센서 고장 → 바닥 화면 2개는 config에서 뺐다. 벽 3면만 쓴다.
    바닥 카메라에서 이상한 점이 들어와도 벽 구역 밖이면 무시된다.
  - 안 만지는데 계속 찍히는 점(고장 난 바닥 센서 등): 브리지가 걸러서 게임에 안 보낸다. 관제 화면에서 회색 점.
      · 벽 구역 밖 점 버리기 (기본 켬)  · 한자리 8초 넘게 있는 점 버리기  · "지금 찍힌 점 모두 무시 등록" → 저장
    업데이트할 때 config.json 은 덮어쓰지 말 것 (보정값이 들어 있음). 새 설정은 없어도 기본값으로 동작.
  - 공을 세게 던지면 안 잡히는 문제: 관제 화면 "터치 기록"으로 확인. 던질 때마다 줄이 생겨야 한다.
    줄이 안 생기면 센서 카메라가 못 본 것 (게임 문제 아님) → YTS 감도 조정 또는 부드러운 공·살살 던지기.
  - 한 번 쳤는데 2~3번 눌린 것처럼 되는 문제: 브리지가 합친다. 150ms 안에 끊겼다 다시 잡힌 점 = 같은 터치,
    이미 눌린 점 바로 옆 새 점 = 버림(관제 화면 '겹침'). config.json "mergeMs", "mergeDist" 로 조정.
  - 감도 지도 결과: 벽 아래 1/4은 거의 안 잡힘 → 게임 목표·공은 그 위쪽에만 나오게 맞춤.
  - 가만히 서 있는 발은 1.5초 뒤 무시된다 (회색 "머무름 무시"). 관제 화면 "머무름 무시(ms)"에서 조정.

고속 트래커 (YTS 대신, 60~120fps) — 세게 던진 공 잡기용
  YTS 는 카메라를 30fps 로만 읽는다. 공이 벽에 닿는 순간(1/30초 안)을 놓친다.
  tracker.py 는 카메라 5대를 60fps(최대 120) 로 직접 읽어 TUIO 3333 으로 보낸다. 브리지·게임은 그대로.
  YTS 파일은 안 건드린다. 언제든 트래커 끄고 YTS 켜면 예전처럼 돌아간다.
  준비 (1회)
    1. Python 3 설치 (python.org). 설치 첫 화면 "Add python.exe to PATH" 체크.
    2. 10_tracker_setup.bat → opencv·numpy 설치 (인터넷 필요).
    3. 12_tracker_fps_check.bat → 카메라마다 "MJPG 640x480 → 실제 ...fps" 확인. 60 이상이면 성공.
  사용
    1_bridge_start.bat → 11_tracker_start.bat (YTS 켜져 있으면 끄고 시작) → 게임.
    시작 후 1초 손 떼기 = 배경 찍기. 미리보기 창에 카메라 5칸.
  처음 1회: 카메라-벽 짝 + 보정 (조작 모니터에서, 키보드로)
    3_screens_close.bat 로 벽 화면 먼저 닫는다 (보정 점이 벽에 떠야 함).
    1. 벽을 손으로 만져 본다 → 초록 원이 뜨는 칸 = 그 벽 카메라.
    2. 숫자 1~5 로 그 칸 고르고 l(좌) f(정면) r(우) a(바닥 왼쪽) d(바닥 오른쪽). 안 쓸 카메라는 n(끄기).
       바닥(a/d)을 처음 고르면 config.json 에 바닥 화면이 자동 추가된다 (바닥 왼쪽 x=5760, 오른쪽 x=7680).
       2_screens_open 하면 바닥에도 테스트 화면이 뜬다. 벽 3면 게임(span)은 바닥을 안 쓴다.
    3. c → "Do not touch" 1.5초 (손 떼기) → 노란 원 20개가 차례로 뜬다. 원 가운데 손바닥 1초 누르고 떼기.
       오른쪽 위 = 카메라가 보는 화면. 손 대면 빨갛게 떠야 한다.
       6초 동안 못 잡으면 자동 건너뜀(빨간 점 = 사각지대). Space = 바로 건너뛰기. 4점 이상이면 보정됨.
       끝나면 "평균 오차" 표시. 건너뛴 자리는 주변 점으로 계산한다.
    4. 벽 3개 다 하고 s (저장). tracker.json 에 저장됨. 업데이트 때 덮어쓰지 말 것.
    보정한 뒤에는 관제 화면 "모서리 보정" 하지 말 것 (트래커가 이미 화면 좌표로 보냄).
  조정 키 (미리보기 창)
    k  안 만지는데 빨갛게 뜨는 곳(벽 아래 띠, 반사광) → 그 칸 고르고 아무도 없을 때 k = 무시 구역. o = 지우기. s 저장.
    t / g  문턱 올림/내림. 안 만지는데 점 뜨면 t, 터치가 안 잡히면 g.
    ] / [  최소 크기. 작은 잡티 점이 뜨면 ].
    w  선택 카메라 640x480 ↔ 1280x720. 1280x720 이 옆으로 더 넓게 보일 수 있음 (60fps). 바꾸면 그 카메라 보정 다시.
    p  카메라 설정 창 (윈도우). 줌(확대)이 걸려 있으면 최소로.
    b 배경 다시 (손 떼고)   m 검출 화면 보기   x / y 카메라 뒤집기 (움직임이 반대일 때)   q 종료
  카메라는 640x480 MJPG 로 받아(실측 약 100fps) 320x240 으로 줄여 검출. 320x240 직접은 이 카메라에서 25fps 라 안 씀.
  공이 1프레임만 찍혀도 "hold_ms"(60ms) 동안 터치로 유지해 게임이 받는다.

게임
  4_fruit_game.bat → 과일 베기 VR실 판. 창 하나가 벽 3면에 걸쳐 뜬다. 조작 모니터엔 관제 화면.
    (브리지 1번 먼저 켜고, 벽 3면 모서리 보정 끝낸 뒤 실행)
    놀이: 3팀 대결 / 2팀 대결(정면 점수판) / 다 같이. 시작 버튼도 벽 터치로 누른다.
    게임 안 "화면 설정"은 건드릴 필요 없다. 벽 위치는 config.json 값이 자동으로 들어간다.
  5_ghost_game.bat → 유령 잡기 대작전. 숲 → 마을 → 성 → 대왕 유령 순서로 장면이 바뀐다 (약 1분 30초).
    가리개 뒤에서 튀어나온 유령을 콕. 고리가 줄기 전에 빨리 누를수록 점수 많음. 동물 친구 누르면 -3.
    놀이: 다 같이(3면) / 3팀 대결 / 정면만. 난이도·높이 선택.
  6_keeper_game.bat → 슈퍼 골키퍼 (3D). 정면 벽 = 골대. 키커가 찬 공이 날아오면 도착하는 곳을 손으로 막는다.
  13_shoot_game.bat → 슈퍼 슈터 (3D). 정면 벽 = 골대. 진짜 공(말랑한 공)을 벽에 차거나 던지면 맞은 자리로 슛.
     골 1점, 과녁 맞히고 골 3점. 골키퍼 쉬움/보통/어려움(움직임). 혼자 10개 / 번갈아 대결 / 20개.
     골대는 벽 위 3/4 안에 그렸다. 바닥으로 굴린 공은 벽 아래(센서 약한 곳)에 맞아 안 잡힌다 → 공을 띄워 차기.
    좌우 벽은 경기장 관중석 + 전광판. 놀이: 혼자/다 같이(10개) / 번갈아 대결(빨강·파랑 5개씩) / 많이 막기(20개).
    난이도: 쉬움(느린 공, 도착 표시 일찍) / 보통(휘는 공) / 어려움(빠른 공). 공 높이 선택.
    3D라 그래픽카드 힘을 쓴다. 끊기면 알려 줄 것 (관중 수·그림자 줄이면 됨).
  7_baseball_game.bat → 무지개 야구왕 (3D). 시작 화면에서 투수 / 타자 고른다.
    투수·타자 모두 왼쪽 또는 오른쪽 벽에서 한다 (시작 화면 "플레이 벽"에서 고름). 정면 = 중계 화면 + 점수판.
    투수: 그 벽에 포수·타자·스트라이크 존(3×3). 공을 던지거나 손으로 찍은 곳으로 공이 간다.
          존 안 = 스트라이크(+1), 노란 칸 명중 +2, 삼진 +3, 컴퓨터 타자를 땅볼·플라이로 잡으면 +2. 볼 4개면 볼넷.
    타자: 멀리 투수가 던진 공이 날아온다. 공이 존에 닿는 순간 그 자리를 콕.
          타이밍 + 위치 정확도 → 홈런(+10) / 안타(+5) / 플라이(+2) / 땅볼(+1). 볼은 참으면 +2.
          친 공은 카메라가 따라가며 수비수가 잡거나 공이 담장을 넘어간다(불꽃놀이).
    놀이: 혼자·다 같이 / 번갈아 대결(빨강·파랑). 난이도·존 높이 선택.
  8_baseball_duo.bat → 야구왕 2인 동시. 왼쪽 벽 = 빨강 선수, 오른쪽 벽 = 파랑 선수. 정면 = 두 선수 점수판.
    각자 투수/타자·난이도 따로 고르고 따로 시작. 둘 다 끝나면 승리 표시 (둘이 같은 파트일 때).

센서 없이 시험
  9_simulator.bat → 가짜 터치 신호를 보낸다. 집 PC에서 게임 만들 때 쓴다.
  마우스 클릭도 터치로 들어온다.

게임 만들기
  public 폴더에 game.html 넣고:
    <script src="/tuio-client.js"></script>
    const t = new TuioTouch();               // 화면은 주소 ?d=front 로 정해짐
    t.on('down', p => { /* p.x, p.y = 화면 픽셀 */ });
    t.on('move', p => {});
    t.on('up',   p => {});
  띄우기: 명령창에서  node launch.js game.html   → 벽 화면 3개에 game.html?d=화면id
  화면 하나만 쓰는 게임이면 그 화면 주소만 열면 된다.

파일
  bridge.js        TUIO 수신 + 웹 서버 (http://localhost:8080)
  launch.js        모니터별 크롬 키오스크 실행 (크롬 없으면 엣지)
  config.json      포트, 화면-모니터 번호, 화면별 센서 좌표 구역
  public/fruit-vr.html  과일 베기 VR실 판
  public/ghost-vr.html  유령 잡기 대작전
  public/keeper-vr.html 슈퍼 골키퍼 (3D, public/lib/three.module.min.js 사용)
  public/shoot-vr.html  슈퍼 슈터 (3D 축구 슈팅)
  public/baseball-vr.html 무지개 야구왕 (3D)
  public/baseball-duo.html 야구왕 2인 (정면 반반, 안에 baseball-vr 두 개)
  public/tuio-pointer.js 창 하나 게임용: TUIO를 진짜 터치처럼 넣어 줌 (게임 코드 수정 없이 한 줄 추가)
  public/          관제(operator) · 화면 테스트(display) · 모니터 번호(identify) · tuio-client.js
  sim.js           가짜 TUIO 송신기
  tracker.py       고속 트래커 (YTS 대신). 설정·보정 = tracker.json (처음 실행 후 s 누르면 생김)
