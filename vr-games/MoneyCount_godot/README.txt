지폐 세기 놀이터 (VR실 정면 벽용)
================================

켜는 순서
  1. YTS.exe 실행 (TUIO 켜기)
  2. vr-tuio-kit 의 1_bridge_start.bat 실행 (검은 창 그대로 두기)
  3. MoneyCount.exe 더블클릭
  * 왼쪽 아래 점이 초록이면 센서 연결됨. "브리지" = 브리지로 연결, "UDP 3333" = 브리지 없이 직접 연결.
  * 처음 실행 때 "Windows의 PC 보호" 창 → [추가 정보] → [실행]

놀이 고르기
  혼자 하기 / 둘이 대결(정면 벽을 반씩, 빨강=왼쪽 파랑=오른쪽)
  1단계 새싹  유치부      천 원만, 모두 얼마인지 화면에 보임
  2단계 열매  유치부~1학년 천 원·오천 원, 모자란 금액 알려줌
  3단계 나무  1~3학년     만 원까지, 합계 숨김, "똑같아요" 문제
  4단계 숲    3학년 이상   오만 원까지, 큰 금액 거스름돈
  놀이: 얼마일까?(지폐 세기) / 값 치르기(가격만큼 내기) / 누가 더 많을까?(비교) / 거스름돈 주기 / 골고루 섞어서
  한 판 8문제. 값 치르기는 3번 틀리면 정답을 보여주고 넘어감.

교사용 키
  S   게임을 띄울 모니터 바꾸기 (저장됨)
  T   터치 받는 벽 바꾸기: 정면 → 좌측 → 우측 (저장됨)
  N   다음 문제로 넘기기
  M   소리 끄기/켜기
  F   전체화면 끄기/켜기
  Esc 처음 화면으로

참고
  버튼은 벽 가운데와 아래쪽(터치가 약한 곳)을 피해 배치함.
  음성 안내는 혼자 하기에서만, 윈도우에 한국어 음성이 있을 때 나옴.
  지폐 그림은 실제 지폐가 아닌 "놀이돈" 디자인.
